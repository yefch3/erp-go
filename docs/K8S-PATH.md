# Kubernetes 升级路线（备而不用）

现在不上 K8s，这个判断没有变：11 个容器一台机器，compose 够用且人人看得懂
（[DEPLOY-PIPELINE.md](./DEPLOY-PIPELINE.md) 第九节）。这份文档存在的理由是
**把"以后"变成一次搬家，而不是一次重写**——记下什么时候该动、动的时候每样
东西去哪、以及今天哪些习惯正在为那一天铺路。

---

## 一、什么时候该考虑（触发条件，满足任意两条再谈）

- [ ] 一台机器扛不住了：CPU/内存持续 >70%，或收信周期追不上
      （DEPLOY.md 五之二的两个数字越线）
- [ ] 需要第二台机器——不管是为了容量还是为了"一台挂了另一台还在"
- [ ] 部署窗口的几秒停机开始有人抱怨（需要滚动更新/蓝绿）
- [ ] 团队里有第二个人能独立排查容器编排问题
      （只有一个人会的技术栈是风险，不是能力）

**反面清单**——这些理由不构成上 K8s 的理由：简历好看、大厂都在用、
听说更先进。300 人试点的全部流量，一台 t3.xlarge 处理起来绰绰有余。

## 二、搬家对照表：每样东西去哪

| 今天（compose 单机） | K8s 里的对应物 | 搬动难度 |
|---|---|---|
| 11 个服务容器 | 各自一个 Deployment + Service | 低——镜像一个字节不用改 |
| `deploy/.env` 非秘密值 | **ConfigMap**（可以进 git） | 低——键值照抄 |
| `deploy/.env` 秘密值 | **Secret**，真身放 AWS Secrets Manager，集群装 External Secrets 自动同步 | 中——一次性录入 ASM |
| host nginx + certbot | Ingress + cert-manager | 中 |
| 前端 nginx 容器 | 原样跑，或静态文件挪去 S3+CloudFront | 低 |
| Redis / Kafka（compose 内） | 试点量级：托管服务（ElastiCache/MSK）比自管省心 | 中 |
| RDS / S3 | **不动**——它们本来就在集群外面 | 零 |
| deploy.sh + SSM | kubectl set image / Argo CD 之类的 GitOps | 中 |
| build.yml 出的 GHCR 镜像 | **原样消费**——K8s 拉的就是这些 | 零 |
| EC2 单机 | EKS（省心贵）或 k3s 自管（便宜费人）| 这是主要的新支出 |

## 三、.env 在 K8s 里的去向（最常被问的一条）

K8s 里没有"机器上的文件"——Pod 今天在这台机、明天在那台机，追着机器放
文件不成立。配置搬进**集群自己的保险柜**，按秘密与否分两堆：

```
今天:   机器 → 该机的 deploy/.env → 容器环境变量
K8s:    集群 → ConfigMap(非秘密，可进 git) + Secret(秘密，永不进 git)
              → Pod 调度到哪，值就送到哪
正经形态: AWS Secrets Manager 存真身 → External Secrets 同步进集群
          换钥匙只改 ASM 一处，集群自己跟上
```

原则一条没变：**代码只引用变量名；秘密永不进 git；每个环境一套值。**
变的只是保险柜的形状。所以今天维护好 DEPLOY.md 那张键值清单，就是在
给未来的搬家打包——到时按"秘密/非秘密"分两堆即可。

## 四、今天已经在为那一天铺路的事（不用额外做什么）

- 每次合并 main 产出 12 个按 SHA 编号的 OCI 镜像——K8s 直接拉，零改动
- 全部配置走环境变量（12-factor）——ConfigMap/Secret 的注入方式一致
- 服务无状态（状态都在 PG/Redis/S3/Kafka 里）——随便调度、随便扩副本
- 网关有 `/api/healthz`——就是将来的 liveness/readiness 探针
- 服务间用名字互相寻址（iam:9001）——换成 K8s Service 名字同形

唯一提前要留意的：**不要往容器本地磁盘写任何要活过重启的东西**
（现在也没有——附件在 S3，这条只是给未来改代码的人立个牌子）。

## 五、量级估算（触发条件满足那天再核价）

- EKS 控制面 ~$74/月 + 至少两台工作节点，全套下来比现在的单机贵 2–3 倍
- k3s 自管省下控制面钱，代价是升级、备份、故障全归自己
- 迁移工时粗估：清单齐备的前提下 1–2 周（含 GitOps、告警、演练），
  大头不是写 YAML，是把"回滚、扩容、坏一台机"各演练一遍
