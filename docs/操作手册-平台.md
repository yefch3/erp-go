# 操作手册（平台版）

> **这一份不要发给客户。** 里面有每家客户的成本数字和额度设置。
>
> 「平台开户」**不是一项权限，是一份单独的名单**（`platform_operators`）。所以
> 客户公司的管理员权限再大也看不到这一页——这是有意的：每家新公司的超管在
> 开户时会被授予全部权限，只要「开公司」是一项权限，它就会自动流进每一位
> 客户管理员手里。
>
> 客户那边怎么用系统，见 [操作手册（客户版）](操作手册-客户.md)。
>
> 最后核对：2026-09-01。

---

## 一、开一家新公司

**动手之前**：你得先在「邮箱」页登录过自己的邮箱。邀请信是**从你自己的邮箱
发出去的**，没登录的话点下去会被挡住，提示「你还没有绑定自己的邮箱」。

| 步 | 在哪 | 做什么 |
|---|---|---|
| 1 | 左侧菜单 → **平台开户** | 进页面 |
| 2 | 右上角 → **开通新公司** | 弹出对话框 |
| 3 | 填 **公司** | 客户公司名称 |
| 4 | 填 **管理员邮箱** | **仔细核对**——邀请发给谁，谁激活后就是这家公司的管理员 |
| 5 | 点 **开通并发送邀请** | |

成功后提示「公司已开通，邀请邮件已发出」，列表里多一行，状态是 **待激活**。

如果看到「公司已开通，但邀请邮件未发出」——公司已经建好了，只是信没发成。
在那一行点 **重发邀请** 就行，不要再开一次公司。

## 二、对方那边怎么激活

对方收到信，点里面的链接，打开「**启用你的账号**」页：

1. 填 **设置密码**（至少 10 位）
2. 填 **再输一次**
3. 点 **启用账号**

看到「账号已启用，现在可以登录了」就成了。你这边的列表状态会变成 **已激活**。

## 三、列表上每一行能做什么

| 按钮 | 什么时候用 | 注意 |
|---|---|---|
| **重发邀请** | 对方没收到、或链接过期了 | **旧链接立刻作废** |
| **额度** | 定这家公司每月能用多少次「智能转换」 | 见下 |
| **停用** | 这家公司不再用了 | 停用后**这家公司所有人都无法登录** |
| **恢复** | 停用之后要放回来 | |

**智能转换额度**（对话框「智能转换额度」）：

- 开关打开 = **设上限**，填「每月次数」；每个自然月 1 号自动重置
- 开关关掉 = **不限**次数
- **填 0 不等于不限**——0 是「一次都不能用」。想放开限制请关掉开关
- 失败的转换一样占次数（模型答了，钱就花了）

列表上还有一列 **本月成本**，是真金白银的数字，这也是这份名单不给客户的原因之一。

## 四、丢下的事件

同一页往下拉，有一块「**丢下的事件**」——后台反复处理失败、被放到一边的事件。

**每一条都对应一笔没记上的业务**（比如合同已签但船运那边没收到通知）。

1. 看 **失败原因** 那一列，把根因修掉
2. 点那一行的 **重放**
3. 看到「重放成功，事件已补记」就好了

> 修好原因之前不要反复点重放——它会用同样的方式再失败一次。

上面还有个 **刷新** 按钮。

## 五、给一个人开平台操作员

**界面上没有这个入口**，只能直接写库。这也是有意的（理由见文件开头）。

要加人时找开发：需要往生产数据库的 `platform_operators` 表里插一行，走 SSM
执行。**这是一次生产写操作**，动手前先只读查一次「这个邮箱对应的是谁」——
邀请、开户、成本都跟着这个身份走，加错人不会有任何提示。

加完之后，那个人**刷新一下页面**就能看到「平台开户」菜单，不用重新登录。

## 六、这份名单管的不只是开户

在名单上的人，同时能看到这三样：

| | 在哪 |
|---|---|
| 平台开户页（开公司、额度、停用） | 左侧菜单 **平台开户** |
| 丢下的事件 | 同一页往下 |
| **每家客户的本月成本** | 平台开户列表的「本月成本」列 |

最后那个是钱的数字。给谁开这份名单之前，先想清楚这一条。
