# 采购管理优化需求清单

> 状态截至 2026-08-17。本文档是采购管理模块的现状盘点、UI 优化及后续功能需求台账：
> ✅ 已完成并实测；⬜ 未做；🔶 部分完成/存在缺口。
> 每完成并实际测试一项，再更新对应状态；页面存在不等于功能完成。

> 本模块已有大量功能，不从零重做。开发时优先复用现有 `mail`、`procurement`、
> `export`、`masterdata`、`inventory`、权限体系和 UI 组件，不修改无关模块。

## 0. 定位

采购管理负责接收已经标准化的客户询盘，组织多工厂询价、报价比较、成本与利润测算，
并在客户接受报价及销售合同生效后，完成采购需求、采购审批、正式下单、履约、收货、
质检、入库和供应商应付对账。

邮件和采购的边界已经确认：

```text
客户 Email
└─ 邮件模块：LLM 标准化客户要求并生成标准 Excel（已经完成）
   ├─ 自动转入采购管理 ─┐
   └─ 员工下载后手动上传 ├─→ 待确认询盘 → 采购询价项目
                         └─ 两种来源共用同一解析、预览和防重复规则

采购询价项目
├─ 多工厂 RFQ → 工厂报价导入 → 价格与交期比较
├─ 码头费 / 海运费 / 汇率 / 利润测算 → 客户报价
├─ 客户拒绝 → 返回原询价项目继续调整
└─ 客户接受 → 销售合同 → 采购需求 → 审批 → 正式下单
                                      → 跟单 / 收货 / 质检 / 入库
                                      → 供应商应付对账与采购结案
```

本次采购优化不重新开发邮件接收、LLM 标准化或标准 Excel 生成，也不删除已有采购数据。

已确认的模块边界：

- ✅ 客户 Email、LLM 标准化和标准 Excel 生成属于邮件模块，现有功能保留。
- ✅ 采购模块的正式起点是已经生成的标准 Excel。
- ✅ 标准 Excel 允许“邮件自动转入”和“员工手动上传”两个入口。
- ✅ 两个入口必须进入同一个“待确认询盘”列表，并使用同一套解析与确认逻辑。
- ✅ 确认标准 Excel 后才生成正式采购询价项目。
- ✅ 现有询价、RFQ、报价、成本、采购需求和采购订单能力优先复用。
- ✅ 新版 UI 先解决流程不清晰和操作拥挤，不重构无关模块。

## 2. 标准询盘进入采购

### 2.1 邮件自动转入

- ✅ 邮件模块已经生成统一标准 Excel。
- 🔶 当前可以从邮件页面直接生成询价项目，但没有统一待确认队列。
- ✅ 标准 Excel 生成成功后，可以自动转入“待确认询盘”。
- ⬜ 记录源邮件 ID、源附件 ID、发件人、文件名和生成时间。
- ⬜ 从采购页面可以返回查看原邮件并下载对应标准 Excel。
- ✅ 同一邮件转换结果只能生成一条有效待确认询盘；数据库唯一约束负责防并发重复。
- ⬜ 自动转入失败不得影响邮件和标准 Excel 已有数据。

### 2.2 员工手动上传

- ✅ 采购工作台和待确认询盘页面均提供“上传标准 Excel”按钮。
- ⬜ 只接受系统规定版本的 `.xlsx` 标准模板。
- ⬜ 校验文件大小、工作表、表头、必填字段、数量和单位。
- ⬜ 上传失败时显示工作表、行号、字段和错误原因。
- ⬜ 记录上传员工、上传时间、原文件名和文件摘要。
- ⬜ 手动上传与邮件自动转入调用同一个后端解析服务。

### 2.3 统一状态

- ⬜ `PENDING`：等待预览确认。
- ⬜ `WARNING`：存在可修正警告。
- ⬜ `CONFIRMED`：已确认并生成采购询价项目。
- ⬜ `VOIDED`：已忽略或作废，保留历史但不进入后续业务。
- ⬜ 状态变更记录操作人、时间、原因及关联询价项目。

## 3. 待确认询盘

### 3.1 列表

- ⬜ 显示编号、来源、客户、联系人、标准 Excel 文件名、产品行数、进入时间和状态。
- ⬜ 来源明确标记为“邮件自动转入”或“员工上传”。
- ⬜ 支持按编号、客户、文件名、来源和状态筛选。
- ⬜ 默认优先显示待确认和存在警告的询盘。
- ⬜ 支持正确分页，并显示与筛选结果一致的总数。
- ⬜ 操作保持简洁：预览确认、查看问题、作废；其他信息进入详情。

### 3.2 防止重复

- ⬜ 同一源邮件和附件不能重复转入。
- ⬜ 对 Excel 内容生成稳定摘要，同一内容重复上传时给出警告。
- ⬜ 相同客户、相近时间和高度相似产品明细提示可能重复。
- ⬜ 重复检查默认提示而不是覆盖已有数据。
- ⬜ 有权限员工确认继续时必须填写原因，并写入变更记录。

### 3.3 预览确认

- ⬜ 显示客户、联系人、来源邮件和标准文件信息。
- ⬜ 表格显示产品、标准、牌号、尺寸、表面、包装、交期、贸易术语、港口、数量和单位。
- ⬜ 支持修改单行错误，忽略空白行、说明行和不需要采购的行。
- ⬜ 提示数量缺失、单位不明、重复行和无法识别字段。
- ⬜ 正常文件支持“全部确认”，不要求员工逐行重复点击。
- ⬜ 至少保留一条有效产品明细才能确认。
- ⬜ 确认后生成正式采购询价项目，并保留来源追溯关系。
- ⬜ 同一待确认询盘只能成功生成一次采购询价项目。
- ⬜ 修改前后值、忽略原因、确认人和时间写入变更记录。

## 4. 采购工作台

工作台面向采购人员每天使用，不重复堆放详细业务字段，也不只是普通菜单导航。

### 4.1 标准询盘入口

- ⬜ 页面顶部突出显示“邮件自动转入”和“员工手动上传”两个入口。
- ⬜ 两个入口直观汇入“待确认询盘”。
- ⬜ 显示每种来源当前待确认数量。
- ⬜ 提供“上传标准 Excel”和“进入待确认询盘”主要操作。

### 4.2 关键数量

- ⬜ 待确认询盘：待确认和存在警告的标准询盘数量。
- ⬜ 进行中询价：尚未完成客户报价的有效询价项目数量。
- ⬜ 采购待处理：待审批和待正式发单的采购订单数量。
- ⬜ 数量按当前员工权限和数据范围计算。
- ⬜ 点击数量进入带正确筛选条件的对应列表。
- ⬜ 不为装饰增加无实际操作价值的统计卡片。

### 4.3 今日重点

- ⬜ 待确认的标准询盘。
- ⬜ 即将到期或已经逾期的工厂 RFQ。
- ⬜ 等待确认的成本方案。
- ⬜ 等待当前员工审批或正式发送的采购订单。
- ⬜ 按紧急程度、截止时间和创建时间排序。
- ⬜ 点击任务直接进入对应记录和操作位置。
- ⬜ 与“我的待办”复用任务数据，不维护两套状态。

### 4.4 异常提醒

- ⬜ RFQ 超过回复期限。
- ⬜ 采购单邮件发送失败。
- ⬜ 供应商交期延误。
- ⬜ 生产、质检或到货异常未处理。
- ⬜ 异常显示严重程度、持续时间和责任人。
- ⬜ 已解决异常退出当前异常列表，历史仍可查询。

### 4.5 业务进度

工作台按三个阶段展示，不把十多个节点挤在一条长流程线上：

1. **询盘进入**：待确认询盘、创建采购询价项目。
2. **询价与客户报价**：多工厂 RFQ、报价比较、成本利润测算、客户报价。
3. **合同后采购**：采购需求、审批、正式下单、生产质检、到货入库、对账结案。

- ⬜ 每个阶段显示进行中或待处理数量。
- ⬜ 每个节点可以进入对应列表。
- ⬜ 当前待处理节点使用明显但克制的状态色。
- ⬜ 客户拒绝报价后回到原询价项目继续调整，不复制无关记录。
- ⬜ 常用桌面分辨率和窄屏下没有文字重叠或操作遮挡。
