# 船期路线与延误跟踪

本功能在 D1 船期基础上增加港口路线、多次延误、进度和到港提醒，不修改其他 ERP 模块。

## 核心规则

- 每条船期保留原始 ETA，并单独维护最新 ETA；最新 ETA 不覆盖原始值。
- 一条船期包含有顺序的起运港、中转港、临时挂靠港和目的港。
- 每次 ETA 变化生成独立延误事件，记录本次变化与累计延误，历史记录不覆盖。
- 路线、ETA、船名航次、状态和进度变化全部写入 `shipping_schedule_changes`。
- 7 天提醒按最新 ETA 和 ETA 版本生成；改期取消旧的待发送任务，同一版本只生成一次。
- 延误 1～3 天显示橙色，4 天及以上显示红色。

## 数据迁移

船期服务迁移版本为 3：

```powershell
go run github.com/pressly/goose/v3/cmd/goose@v3.24.0 -dir services/shipping/db/migrations postgres "<DSN>" up
```

回滚本次迁移：

```powershell
go run github.com/pressly/goose/v3/cmd/goose@v3.24.0 -dir services/shipping/db/migrations postgres "<DSN>" down
```

迁移会把已有船期的装港、卸港转换为起运港、目的港节点，并从现有 ETA 初始化原始 ETA 和第一版提醒，不删除现有船期数据。
