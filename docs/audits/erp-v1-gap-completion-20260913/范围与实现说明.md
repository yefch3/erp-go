# D1–D7 待确认项补齐

基线：`codex/erp-v1-rebuild-20260906` 的 `aeb01136`。本分支只补齐三个已确认口径，不改变 D1–D7 其他业务边界。

## 质检与采购协同

- 质检模块继续只对质检岗位开放。采购从采购单申请质检，但不能进入质检任务页。
- 每轮提交后，若仍有未合格数量，系统把任务标记为“采购待处理”，只进入该采购单负责人的“我的待办”。
- 采购单详情展示只读的结论、送检/合格/不合格数量、异常说明及附件。
- 采购负责人可记录返工、换货、取消缺少数量及结果说明。返工或换货后仍等待质检复检；取消缺少数量后本次质检处理完成。
- 旧“部分合格放行”接口固定拒绝，页面不再显示允许先发数量。只有无未解决数量，或采购明确取消缺少数量后，才结束本次质检处理；一份合同仍只有一次运输。

## 五公式输入与锁定

- 采购报价逐产品提供工厂价、FOB 报价、分条费；公式 1/2 取 FOB，公式 3/4/5 取工厂价，公式 4/5 同时取分条费。
- 物流报价提供短导、内陆、港杂、海运费和运输天数；销售选择物流报价时按费用名称带入对应字段。
- 每销售单位吨数优先由产品需求的总重量 ÷ 数量取得；单位为 MT 时自动为 1；仍缺少时由销售补充。
- 销售选择公式并手工填写、勾选确认本次 `USD/CNY` 报价汇率。D7 汇率页仅供参考，不再被报价计算自动读取。
- 计算价与销售最终单价分别保存。客户确认后，客户报价 `body`、上游 `source_snapshot`、计算价及最终单价随确认记录锁定，现有不可编辑保护继续生效。

## 物流费用分摊

- 物流逐笔费用选择：产品专属、按吨、整票固定；产品专属费用必须指定产品。
- 产品专属费用全额计入该产品；按吨费用使用产品合同重量；整票固定费用按各产品合同重量比例分摊。
- 金额按币种分别计算到 2 位小数，整票分摊尾差进入最后一项产品，不做跨币种换算汇总。
- 分摊结果冻结在客户报价内部快照，只用于产品成本和利润分析。财务登记的物流付款仍为一笔，不因产品分摊拆单。
