## 1. 财务放行

1. 用财务账号进入“财务 → 入账”。
2. 找到 `CT-202609-0010`，确认合同已经执行，但采购和物流正式任务尚未生成。
3. 确认执行条件。可选择“无需预付款即可执行”，填写验收备注后提交。
4. 刷新后确认该合同只生成一次采购待重新询价需求和一次物流待重新询价任务。

## 2. 采购重新询价和拆单

1. 用采购账号进入“采购管理 → 采购订单”。
2. 在“待确认工厂报价”看到该合同的 3 项产品，售前工厂与价格只显示为参考。
3. 点击“统一确认并自动拆单”。把至少一项产品改选为另一家工厂，分别填写最终币种、单价、预计交货日期、付款方式和报价有效期。
4. 保存后确认同一最终工厂的产品在同一张订单，不同工厂拆成不同订单；两张订单展示号均为 `CT-202609-0010`，供应商和明细不会串单。
5. 逐张提交上级确认。用上级账号在“我的待办”同意采购订单。
6. 返回采购账号，确认订单进入待签采购合同；上传各自正确的已签采购合同。
7. 用财务账号核验两份采购合同，再用采购账号分别申请付款。
8. 在“财务 → 出账”确认出现两笔采购付款申请，收款方、合同号、金额、币种、附件和申请人对应各自最终工厂。

## 3. 物流重新询价

1. 用物流账号进入“物流 → 实单物流”。
2. 打开 `CT-202609-0010`，确认售前货代和方案只在参考区显示，最终货代尚未锁定。
3. 选择最终货代和实际承运船公司，填写航线/方案、最终运费、币种、ETD、ETA、付款条件和唯一货代合同号后提交。
4. 用上级账号在“我的待办”同意“实单物流报价确认”。
5. 返回物流账号上传已签货代合同；用财务账号完成合同核验；再用物流账号申请付款。
6. 在“财务 → 出账”确认物流付款申请的收款方是最终货代。即使实际承运船公司不同，也不能把船公司当成合同或收款对象。
7. 回到物流任务查看申请金额、已付金额和未付金额。

## 4. 边界检查

- 客户报价和外销合同仍保留原来已确认内容，内部更换工厂、货代或船公司不会回写客户文件。
- 合同核验前不能申请付款；退回后在原订单或原物流任务中修改并重新提交。
- 当前页面不出现备货、质检、订舱、开航、到港等 D5 及后续操作。
- 五公式输入口径与物流费用分摊保持原状，本轮不验收其计算规则。

以上步骤符合即可确认 D4 通过。发现问题时请记录账号、合同号、当前状态、操作步骤和页面提示。
