## 1. 财务放行

1. 用财务账号进入“财务 → 入账”。
2. 找到 `CT-202609-0010`，确认合同已经执行，但采购和物流正式任务尚未生成。
3. 确认执行条件。可选择“无需预付款即可执行”，填写验收备注后提交。
4. 刷新后确认该合同只生成一次采购待重新询价需求和一次物流待重新询价任务。

## 2. 采购实单询价、选择工厂和生成草稿

1. 用采购账号进入“采购管理 → 实单询价”，打开 `CT-202609-0010`。
2. 确认页面只有 3 项合同产品；售前工厂和价格只显示为参考，缺失的售前快照应明确显示“未带入”，不能显示成零报价。
3. 点击一次“添加一份工厂报价”，选择工厂和公共报价条件，并在同一窗口填写该工厂对本批产品的单价；不供应的产品可以留空。再次添加另一家工厂，即可为同一产品保留多家工厂的新报价。
4. 刷新页面，确认多条报价仍然存在；可修改或删除未选报价。为每项产品各选择一条最终报价。
5. 三项产品都已选择后点击“生成采购订单草稿”。确认系统按最终工厂、币种、交货日期和付款方式自动分组；同组进入同一张草稿，不同组生成不同草稿。
6. 系统进入“采购管理 → 采购订单 → 草稿”。逐张检查供应商、合同号、产品、数量、单价、币种、交货日期和付款方式，确认与所选报价一致后提交审批。
7. 用上级账号在“我的待办”处理采购订单：同意后订单进入“采购合同”；退回时填写原因。
8. 验证退回路径：采购订单列表中不出现“已驳回”分类或订单；对应产品重新出现在“实单询价”，采购可以补充新报价、重新选厂并生成新草稿。
9. 对审批通过的订单上传已签采购合同，确认订单仍在“采购合同”页签并显示“待财务审核”；用财务账号在“出账”的“更多操作”中选择“审核并批准付款”，确认订单随后进入“已下单”。
10. 在“财务 → 出账”确认采购付款申请的收款方、合同号、金额、币种、附件和申请人对应最终工厂。

## 3. 物流重新询价

1. 用物流账号进入“物流 → 实单物流询价”。
2. 打开 `CT-202609-0010`，确认页面显示合同产品名称、规格、数量、单位和备注；售前货代和方案只在参考区显示，最终货代尚未锁定。
3. 选择一家货代，填写航线/方案、运费、币种、ETD、ETA、付款条件和备注；实际承运船公司可留空，待后续宣船时补充。点击“保存候选方案”，然后更换货代或条件再保存至少一份，确认前一份不会被覆盖且任务仍留在“实单物流询价”。
4. 在“实单物流询价”选中最终方案并点击“提交到草稿”。进入“物流 → 物流订单 → 草稿”，确认这里只展示已选方案；复核后点击“提交审核”。用物流上级 LM1 账号在“我的待办”处理“实单物流报价确认”，并确认待办可直接定位到“审批中”的对应单据。
5. 返回“物流订单 → 物流合同”，填写唯一货代合同号并上传已签货代合同；同一页状态显示“待财务审核”。
6. 用财务账号进入“财务 → 出账”，确认收款方是最终货代，在“更多操作”中审核并批准付款。即使实际承运船公司不同，也不能把船公司当成合同或收款对象。
7. 回到“物流订单 → 已委托”，确认对应订单已进入该状态，并提示下一步为宣船。本 D4 不执行宣船。

## 4. 边界检查

- 客户报价和外销合同仍保留原来已确认内容，内部更换工厂、货代或船公司不会回写客户文件。
- 财务批准前物流订单不能进入“已委托”；审批退回后回到实单物流询价重新修改和提交。
- 当前页面不出现备货、质检、订舱、开航、到港等 D5 及后续操作。
- 五公式输入口径与物流费用分摊保持原状，本轮不验收其计算规则。

以上步骤符合即可确认 D4 通过。发现问题时请记录账号、合同号、当前状态、操作步骤和页面提示。
