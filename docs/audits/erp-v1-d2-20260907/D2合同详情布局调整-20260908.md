# D2 合同详情布局调整

- 按用户要求将审批进度从产品与文件之间移至详情下方、版本历史之前。
- 展示顺序：合同信息与状态操作、产品明细与金额、客户运输方案、合同文件、已有执行相关信息、审批进度、版本历史。转移、发货、船期、收款区域仍按原数据和权限显示。
- 运输方案独立成卡片，从文件上传区移出；接受状态使用标签，货物明细限制显示高度并可滚动。
- 审批由居中横向步骤条改为紧凑列表，显示轮次、状态、提交人、审批节点、审批人及时间，意见单独高亮；审批历史限制高度，避免轮次过多撑长页面。
- 合同文件限制表格高度；顶部状态操作区域采用浅蓝背景，卡片标题、边框和留白统一。
- 浏览器以 B1 查看合同249，实际核对运输→文件→发货→审批→版本顺序以及退回意见完整显示。未点击审批、保存、上传或执行操作。
- 第二轮视觉调整统一字体层级：正文与表格内容 14px 常规字重，表头 13px 半粗，区域标题 16px 半粗，辅助信息 12–13px 灰色，关键合计 20px；避免同级文字随意加粗。产品规格限制三行，详情抽屉扩大至 1040px，提升长规格和多列表格的可读性。
- 审批进度进一步改为纵向时间线：轮次标题与提交人/提交时间同排，审批节点、结果、审批人和处理时间形成固定层级，意见使用紧凑浅色条展示；移除旧步骤条残留样式，避免字体和间距互相覆盖。
- 合同明细及其下方区域统一增加折叠标题栏。合同明细和客户运输方案默认展开；合同文件、转移历史、发货进度、船期、收款、审批进度和版本历史默认收起，并在收起状态展示项目数、轮次、金额等摘要。审批内部间距和状态标记同步缩小。
- 浏览器实际检查产品、金额、运输、文件、发货和审批区域的字体层级及滚动效果；前端类型检查通过。
- 仅局部前端展示修改，无数据库或业务流程变更，定价规则继续暂缓。保留在 D2 独立工作区，未合并。
