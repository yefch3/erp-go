## 建议验收步骤

1. 使用 P1 登录，进入“采购管理 → 采购订单”，在 `PO-D5-ACCEPT-001` 的“更多操作”中点击“申请质检”。填写本次送检数量 `6 MT`、计划日期、地点、联系人和备注后提交。确认该操作不出现审批步骤。
2. 再次尝试对同一产品提交超过剩余数量的批次，页面应提示累计送检数量不能超过采购数量；合法的剩余批次仍可稍后申请。
3. 使用 Q1 登录，打开独立“质检”模块。顶部应只有“待质检”和“已完成”两个标签。在“待质检”中打开任务并开始质检。
4. 第一轮把该产品记录为“部分合格”，合格 `4 MT`、不合格/待复检 `2 MT`，填写异常说明、处理建议和备注。分别上传现场照片或视频、质检报告、第三方报告及其他附件中的若干项并提交。
5. 确认任务仍留在“待质检”，同一任务内显示第一轮完整结论、附件和时间/操作人历史；随后在同一任务发起下一轮，将剩余 `2 MT` 记录为合格并上传复检资料。
6. 确认该任务移入“已完成”，逐产品累计合格数量为 `6 MT`，两轮历史和每轮附件均可重新打开或下载。
7. 使用 P1 打开质检任务。对第一轮部分合格场景可填写允许先发数量（不得大于累计合格数量）；确认采购可以作出该决定，但不能修改质检结论。
8. 分别使用 L1、S1、B1 登录并进入“质检”。确认可以按各自数据权限查看任务、合格数量、历史和附件，但看不到“开始质检”“提交本轮结论”等编辑操作。
9. 回到 P1，再对该采购单申请剩余 `4 MT`。确认系统允许形成第二个分批任务；随后再次申请任意正数应被累计数量上限拦截。

## 数据与权限口径

- 采购和物流读取同一套质检任务及逐产品累计合格数量，不复制易失真的独立数字。
- `PASS`、`PARTIAL`、`FAIL` 只能由质检角色写入；采购的“允许先发数量”是独立字段，不会改写质检结论。
- 每轮现场资料保存文件元数据、分类、所属任务/轮次和对象存储键；打开资料时生成新的受控下载地址。
- 异常不会创建游离的新任务，而是在原任务中追加复检轮次，保留完整审计历史。
