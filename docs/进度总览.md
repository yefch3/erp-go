## 零、一句话结论

**主干做完了，边缘没动。**

一条外贸单子从客户询盘走到收款，中间每一步在系统里都有落点，而且是通的：
询盘 → 工厂询价比价 → 成本方案 → 客户报价 → 合同 → 采购需求 → 采购单 →
审批发单 → 工厂回签 → 到货质检 → 结案 → 供应商发票三单核对 → 付款核销 →
银行流水对账。船期、应收催收、提单提醒、信用评级、邮件系统、平台开户也都在跑。

没做的集中在三处，而且**这三处从来没被任何一次核验碰过**：

| | 功能缺口 | 状态 |
|---|---|---|
| **仓库管理** | 156 条 | 有 8 个页面和基础库存模型，深水区（库区库位、批次序列号、拣货、调拨、盘点、提醒）全空 |
| **我的待办** | 144 条 | 只做了审批那一路（HOME1），其余七类来源全是稳定空状态 |
| **产品管理** | 92 条 | `product` 服务只有 2 个迁移、1735 行；清单里除「已有能力摘要」外，功能章节 ✅ 数为 0 |

另有一份 **10 条实质缺陷** 的修复清单躺了 9 天没人动（第四节，本次逐条核过）。

A4 全线上线了（`order_import.go`、`purchase_template.go`、`supplierrecon_*`
一整套在库）。真没做的只有报表那半（见第三节）。

**三、修复清单 H3「REFUND 无方向语义」还是空框**——早修了。

## 五、明确不做 / 已决定搁置的

**这一节和「还欠什么」一样重要。** 不写下来的话，下一个人会把它们当成漏洞补回来。

| 内容 | 为什么不做 | 出处 |
|---|---|---|
| **按「在线状态」决定收不收邮件** | 邮件不等人上线——凌晨两点的西班牙客户询价会在系统里消失七小时，而西语客户正是主要客群。而且成本反了：为了够实时得给每个用户开一条 WebSocket，等于为省一个常驻系统建了另一个 | 开发计划 E6 |
| **邮件统一收件箱** | 两个箱同时收到同一条会话时那是两行。合成一行，「这封信该从哪个箱回」就答不上来 | 开发计划 F5 |
| **「连历史邮件一起彻底删掉」** | 只有设计，没有实现。解绑之后 `email_inbound`、附件、对象存储里的原始 MIME 都还在，地址也还被 `UNIQUE (tenant_id, email)` 占着。要真删得连对象存储一起清且不可逆——**留到有人真的提出来再做** | 开发计划 F5 |
| **AIS 船舶位置追踪（E4 丙）** | 它追的是**船**不是**你的货**。船到港 ≠ 你的柜卸下来了 ≠ 你能提货。适合大屏，不适合驱动业务 | 开发计划 E4 |
| **拔掉 `payment_days`（F3）** | 要为一个没人读的整数列付两次大改名（sqlc 会在共用行类型和独立行类型之间来回切，app 层三十来处跟着动两遍）。不做的代价接近零 | 开发计划 F3 |
| **CSV 对账单导入的前端入口** | 用不到；各家银行的 CSV 列名编码日期格式全不一样，没样本就上线，第一次用必然导进来一堆歪的行。后端整条路留着，把按钮放回来就行 | 开发计划 F4 |
| **自建身份中心（SSO 的一种做法）** | 只有一个系统时，自建等于把登录搬个家：员工没登着那个中心，照样要输密码，密码数量没变还多一次跳转和一个要运维的服务 | 开发计划 E5 |
| **船舶主数据 / 船期的合同与单证阶段 / 导入导出审计 / 并发编辑冲突提示** | 清单自己标着「确认是否建立」；等前两档清空后再议 | 开发计划 §四 |
| **单证制作 + 统计分析（D4）** | 前者等船期单证真用起来；后者等数据积累——**空库上建报表没意义** | 开发计划 D4 |
| **「货到了但整单要推翻」** | 50 吨已在码头库里，作废会让这批货不属于任何订单、开不了票也付不了款。应该走关单那条路。**待业务确认这种场景是否真实存在** | 开发计划 A5 |

### 上线了但要记着的两处代价

| 内容 | 代价 |
|---|---|
| **收款对账现在离不开采购服务** | 以前它只读自己的库，现在每次翻页都要问采购。采购挂了，收款对账**整页打不开**——不是少几行。这是故意的：给个空列表看起来像「这个月没有收款」 |
| **发信侧的「退出即禁用」只挡日常路径** | 写信框只列还开着的箱，但服务端一个请求只带一把令牌，验不了「你是不是也开着那个箱」。拿别人的箱 id 发信会被拒，拿**自己已退出的**箱发信不会 |
| **容量分档是按 300 人拍的** | 不是按现在的真实规模。真实数字小得多；规模变了要回头重估 `MAIL_SYNC_*` 那三个旋钮 |
