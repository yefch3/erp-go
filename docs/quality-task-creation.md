# 质检页面新建质检单

质检页面增加「新建质检单」，使用已有采购单建立整单质检任务。沿用现有质检单、产品行、结果、复检、附件和异常处理数据结构，新增 00074 迁移保存基本资料修改和删除审计，其余沿用现有数据表。

## 操作

- 搜索采购单号或供应商，分页选择采购单。
- 自动显示供应商、产品、规格、单位、数量，不能在质检单中改采购产品和数量。
- 可填写预计质检日期、地点、联系人、电话、要求/备注。采购单没有质检现场联系人字段，因此这些内容由用户填写，不把收货地址误当成质检地点。
- 创建后打开详情，状态为待质检。
- 已有任务显示「打开原单」，并发重复创建复用原任务。复检继续在原任务中记录。

## 权限及接口

三个新接口同时要求 `quality:task:read` 和 `quality:task:write`，不额外授予质检人员采购详情读取权限：

- `GET /api/quality/source-orders`：可质检采购单列表，支持关键词和分页。
- `GET /api/quality/source-orders/{id}`：仅质检所需产品资料。
- `POST /api/quality/tasks`：从已有采购单建单。

来源查询和创建使用现有 quality Data Scope；每次查询及创建均使用登录上下文中的 tenant_id。来源接口不返回单价、金额、付款条款。仅采购业务且已下单/部分收货的单据可新建；已有质检任务仍可查询并打开。原采购页面的申请接口继续使用采购权限。

## 验证

新增数据库集成测试覆盖 quality 数据范围、跨租户拒绝、产品数量、日期校验、草稿采购单拒绝、并发创建幂等、已有任务返回。既有质检生命周期测试一并回归。另运行网关及采购应用测试、Vue 类型检查和生产构建。

本分支使用独立工作目录，未替换原开发目录中的外销合同改动，本地采购服务和网关已切换到质检分支镜像，前端 5173 使用本工作目录。

## 更多操作、编辑与删除

- 列表操作改为「更多操作 ▼」：处理/查看详情，编辑基本资料，满足条件时显示删除。
- 编辑接口 `PATCH /api/quality/tasks/{id}/basics` 要求现有质检读写权限；校验 quality 数据范围及 tenant_id。只允许修改日期、地点、联系人、电话、要求/备注；已完成任务不能编辑。
- 删除接口 `DELETE /api/quality/tasks/{id}` 在采购服务再次校验最高权限。沿用 IAM 的 supplier 范围最高角色判定（该范围的 All 仅授予当前租户有效 SUPER_ADMIN），不能用 quality 的 All 判定管理员。
- `GET /api/quality/access` 返回当前用户删除资格。每张单的 deletable 由后端计算，须处于 WAITING、没有开始时间、没有轮次和附件。
- 删除持有行锁，检查状态与关联记录，事务内保存原单及产品行快照后删除；普通质检人员不能删除。审计表不外键引用原任务，重新建单后仍可追溯旧 ID。
- 本地数据库已应用 00074；其他环境部署前需执行采购迁移。运行数据库集成测试覆盖资料回填、跨公司/超范围编辑拒绝、普通人员删除拒绝、附件/已开始任务删除拒绝、已完成任务编辑拒绝、删除审计及重新建单。
