## 一、员工与账号

| 步 | 在哪 | 做什么 |
|---|---|---|
| 1 | 左侧 → **基础数据** → **员工管理** | |
| 2 | 右上角 → **新建员工** | 先把人建档（姓名、部门、邮箱等） |
| 3 | 在那一行 → **更多** → 账号 → **发送邀请** | 已经发过的话这里显示 **重发邀请** |
| 4 | 对方收信、点链接 | 见下面「对方那边怎么激活」 |

**一次邀请很多人**：在列表里勾选多行 → 顶部 **批量邀请（N）**。可以同时在
「分配角色」里给他们设角色，留空则不改动。

邀请信同样**从操作人自己的邮箱发出**——所以管理员也得先登录过邮箱。

**其它账号操作**（都在那一行的「更多」里）：

| 按钮 | 做什么 |
|---|---|
| **发送重置链接** | 给对方邮箱发重置密码的链接，1 小时有效。**你不会看到对方的新密码** |
| **结束登录** | 让对方手上所有登录状态立刻失效，被退回登录页。不影响他重新登录 |
| **角色** | 改这个人能用哪些功能 |

---

### 对方那边怎么激活

对方收到信，点里面的链接，打开「**启用你的账号**」页：

1. 填 **设置密码**（至少 10 位）
2. 填 **再输一次**
3. 点 **启用账号**

看到「账号已启用，现在可以登录了」就成了，这个人从此可以用自己的邮箱地址登录。

## 二、邮箱

左侧菜单 → **邮箱**。

### 2.1 第一次进来：登录邮箱

会看到一道门，标题「**登录邮箱**」。这道门问的是**邮箱自己的密码**，不是 ERP
的密码——系统会拿它去邮件服务器真登录一次，通过了才让你进。**首次登录成功
就等于把这个邮箱绑上了**，不用另外做绑定。

**Gmail**：点 **用 Google 登录**，在 Google 页面上挑账号、授权，自动跳回来。

**263 / QQ / 163 / 企业邮箱**：

1. 填 **邮箱地址**
2. 选 **选择邮件服务商**（认不出来时可留空）
3. 填 **邮箱密码 / 客户端授权码**
4. 点 **用密码 / 授权码登录**

> Gmail 填应用专用密码；263 这类填账号密码或客户端授权码——**同一个输入框**，
> 服务器认哪个就用哪个。

**服务商列表里找不到你的企业邮箱**：选 **其他（自己填服务器）**，然后填
**发件服务器 SMTP** 和 **收件服务器 IMAP**（域名 + 端口，常见 993 / 465 / 587）。
这两个地址问贵司的邮箱管理员，或者在服务商的帮助页上查。

### 2.2 登录能保持多久

**30 天，而且用着就自动续。**

规则是：每次你打开邮箱页，系统看这把「钥匙」还剩多久——**剩不到一半（15 天）
就直接续满 30 天**。

| 情况 | 结果 |
|---|---|
| 半个月内用过邮箱 | 什么都不发生，继续用 |
| 隔了半个月以上再用 | 那一次自动续回 30 天 |
| 整整 30 天没打开过 | 过期，要重新登录一次 |

一句话：**只要每半个月用一次，就不用再登。**

**每个邮箱各有各的 30 天**，互不影响。

点「退出当前邮箱」或「全部退出」是**立刻作废**，不用等 30 天——共用电脑走人前
点一下就行。

> **和 ERP 登录是两回事。** 进 ERP 的那次登录（公司邮箱 + 密码）自己有一个
> 期限，**5 天**，也是用着就自动续。所以会出现「邮箱还开着，但要重新登录
> ERP」——那是外面那道门到期了，重新登进来之后邮箱不用再验一次。

### 2.3 多个邮箱：左栏「邮箱地址」

绑了不止一个之后，左栏下方「邮箱地址」下面会列出你所有的箱。

| 你看到的 | 意思 |
|---|---|
| 名字后面的红色数字 | 那个箱有多少封没读的。**当前这个箱不显示**（右边列表已经说了） |
| **默认** | 写信时预选这个箱当发件人 |
| **已解绑** | 这个箱断开了，只能看历史邮件，不能收发 |

**点一个地址就切过去**，右边整个列表跟着换成那个箱的信。

⚠️ **每个箱要各自登录一次**。以前登一个箱等于把所有箱都打开了，现在不是了
——切到一个还没登过的箱会弹出那道门。登过之后那个箱自己也有 30 天，见上面
「登录能保持多久」。

每一行右边两个图标：

| 图标 | 做什么 |
|---|---|
| 电源图标 | **解绑这个邮箱** |
| 星星 | **设为默认发件箱**（已经是默认的那行没有这个） |

**「＋ 添加邮箱」** 加第二、第三个箱，填法和上面登录一样。

### 2.4 解绑一个邮箱

点那行的电源图标，确认。

**解绑 ≠ 删除。** 断掉的是连接：不再收发、不再占用同步。**已经收到的邮件全部
保留**，那一行还在左栏里、标着「已解绑」，点进去照样能看能搜。

想恢复：重新填一次授权码就行（走「添加邮箱」或点进去那道门）。

### 2.5 写邮件

1. 左上角 **写邮件**
2. **发件人** 下拉——**只有绑了不止一个邮箱时才出现**。默认是你当前在看的那个箱
3. **发送方式**：
   - **分别发送（每人一封）** = 每人单独收到一封，互相看不到对方，可以用变量个性化
   - **合并一封（互相可见）** = 一封信发给所有人，收件人和抄送名单公开；适合写给
     同一家客户的几个人，但**不能用按收件人变化的变量**
4. 填 **收件人** / **主题** / **正文**
5. 点 **发送（N 封）**

其它按钮：**存草稿**、**预览**、**套用模板**（从已有模板里挑一个填进来）。

**回复的发件人**：对哪个箱收到的信点回复，就默认从哪个箱发出去——除非你在
下拉里手动改。

### 2.6 收信和文件夹

| 按钮 | 在哪 | 做什么 |
|---|---|---|
| **立即收信** | 右上角 | 马上去服务器拉一次，不等后台轮询 |
| **全部已读** | 右上角 | 把当前这个箱当前这个文件夹全标成已读 |
| 搜索框 | 右上角 | 搜发件人或主题，**跨文件夹** |
| **排序：发件人 · 主题 · 日期 · 大小** | 列表正上方那一行 | 点一列按它排，再点同一列反过来。已发送那边「发件人」换成「收件人」。按**大小**排时每行右边会显示邮件大小。搜索的时候这一行不出现 |

左栏文件夹：收件箱 · 星标邮件 · 草稿箱 · 已定时 · 已发送 · 待处理 · 归档 ·
垃圾邮件 · 回收站 · 拒收名单。

打开一封信，附件在正文上方，每个附件后面两个彩色按钮：绿色 **预览**（图片和
PDF 才有）、蓝色 **下载**。

**待处理** 是发出去但出了问题、需要人看一眼的信（退信、地址不对等）。

### 2.7 离开电脑之前

| 按钮 | 做什么 |
|---|---|
| **退出当前邮箱** | 只退你正在看的这个箱，别的箱还开着 |
| **全部退出** | 手上所有箱一起退。**共用电脑走人时用这个** |

## 三、银行流水与对账

**这是两件事，分开做。**

- **银行流水**：银行说钱怎么走的，一笔一笔记下来
- **对账**：这张采购单/合同付了多少、收了多少，还差多少

⚠️ **两者不强绑定。** 记核销时**不要求**你指定是哪一笔流水，金额和日期都是
**人填的，系统不做核对**。这是 2026-08-29 定的口径。

### 3.1 银行流水

左侧 → **财务** → 银行 → **银行流水**。

#### 先把自己的户头登记好

右上角 **收款账户** → **新增账户** → 填户名、账号、开户行、币种。

**为什么要做这一步**：外币户结汇到人民币户，在流水上看起来就是一笔大额货款。
登记了自己的账户，系统才认得出这是内部划转，不是客户打款。

#### 登记一笔流水

右上角 **登记流水**：

| 分段 | 填什么 |
|---|---|
| **这笔钱** | 方向（**入账** 绿 / **出账** 橙）、金额、日期（钱到账/出账那天） |
| **走的哪个户头** | 收款账户（选填）、**银行流水号**、对方户名、附言 |
| **归属与凭证** | 归属、细分、对账单（PDF 或图片，选填） |

**银行流水号很要紧**——重复录入靠它挡住。同一个号再录一次会被跳过。

**「收款账户」里没有这个户头**：直接写一个名字，保存时会按它建一个新账户，
之后再去「收款账户」里补开户行。

**归属**决定这笔钱**接下来能被谁核销**：

| 归属 | 什么时候选 |
|---|---|
| 待处理 | 还没想好 |
| 客户往来 | 要对到客户合同上 |
| 供应商往来 | 要对到采购付款单上 |
| 出口退税 | 退税款 |
| 不用核销 | 银行利息、内部划转、保证金退回等（在「细分」里再选一个） |

> 归属**不是收付方向**：供应商退款是钱进来的，但归「供应商往来」。

⚠️ **目前没有「导入对账单」的按钮。** 各家银行导出的 CSV 格式都不一样，没对过
真实样本就上线的话第一次用必然导进来一堆歪的行，所以入口先收起来了。现在
一笔一笔登记。

#### 列表上能做什么

上方两个页签：**流水**（日常用）/ **已删除**（查账用）。

| 按钮 | 什么时候有 | 做什么 |
|---|---|---|
| **编辑** | 「流水」页签 | 改这一笔。**改归属、传对账单都在这里面**，没有单独的按钮 |
| **删除** | 「流水」页签 | **必须写原因**。删除是归档，这一行移到「已删除」里留着，不会真消失 |
| **取消匹配** | 已经对上号的行 | 解开这笔流水和付款单的关联，银行那一行不动 |
| **恢复** | 「已删除」页签 | 放回「流水」列表 |

**改流水必须写「修改原因」，删流水必须写「删除原因」**——事后查账的人只能
看到你写的那句话，所以写清楚为什么，不要写「改一下」。

### 3.2 供应商对账（应付）

左侧 → **财务** → 应付 · 供应商 → **供应商对账**。

**一张采购单一行：付了多少由人填，算不算完也由人说。**

两个页签：**待核销** / **已完成**。

顶部三个数字，点了就是筛选：

| | 意思 |
|---|---|
| **已逾期** | 过了约定的付款日还没付清 |
| **30 天内到期** | 该安排付款了 |
| **未填到期日** | 建单时没填，在这里补 |

#### 记一笔付款

点那一行 → **记一笔付款**：

1. **这笔是**：付款 / **退款**（退款也填正数，左边选「退款」）
2. **金额**
3. **付款日期**
4. **备注**（例如：电汇尾款 / 订金）

> 数字由你填，系统不核对——只有一条规矩：**退款不能超过这张单已付出去的钱**。

#### 确认完成

**记完付款不会自动完成。** 要另外点 **确认完成**：

1. 选 **为什么算完了**：正常付清 / 认亏 / 尾差 / 订单取消 / 其他
2. 写 **备注**——写给以后的人看，当时是怎么定的
3. 点 **确认完成**

> 完成与否**由你说了算**：差额是多少都可以确认，确认之后照样能继续记付款。

弄错了：在「已完成」页签点 **撤销完成**，写明原因，回到「待核销」。

#### 其它

| 按钮 | 做什么 |
|---|---|
| **改到期日** | 补或改应付到期日，要写「为什么要改」 |
| **上传凭证** | 发票、水单、退款回执都放这儿，可以传好几份 |
| **撤下** | 撤下一份凭证。记录留着，谁在什么时候撤的查得到 |
| **冲销** | 某一笔记错了，冲掉它，要写明原因 |

### 3.3 客户对账（应收）

左侧 → **财务** → 应收 · 客户 → **客户对账**。

和供应商对账**一模一样的做法**，只是方向反过来，账期从合同生效日起算：

| 供应商对账 | 客户对账 |
|---|---|
| 一张采购单一行 | 一张合同一行 |
| **记一笔付款** | **记一笔收款** |
| 付款 / 退款 | 收款 / 退款 |
| **确认完成** | **收款结清** |
| **撤销完成** | **撤销结清** |

> **收款结清只是停止催收和提醒。** 这张合同照样能核销——钱真的又来了，
> 撤销结清即可。

三个数字（合同金额 / 已收 / 差额）在每一行上。

## 容易踩的几件事

| | |
|---|---|
| 发不出邀请信 | 邀请信从**你自己的邮箱**发出。先去「邮箱」页登录一个箱 |
| 切邮箱又要输密码 | **每个箱各自登录一次**，登过之后那个箱 30 天内不再问 |
| 找不到「导入对账单」 | 目前没有这个按钮，一笔一笔登记 |
| 找不到「改归属」按钮 | 在 **编辑** 里面 |
| 记了付款单子还在「待核销」 | **完成要另外点**「确认完成」/「收款结清」 |
| 删了流水找不到了 | 在「**已删除**」页签里，点 **恢复** 放回来 |
| 邮箱隔很久没用要重登 | 30 天没打开过就过期了。平时用着会自动续 |
