# 财务收支简化

## 目标

财务页面只回答三件事：银行实际发生了什么、客户的钱收了多少、供应商的钱付了多少。界面使用日常语言，不要求员工理解“核销”“期初应收”“期初应付”等专业词。

## 页面顺序与名称

财务菜单固定为：

1. 银行流水
2. 入账
3. 出账
4. 汇率

原“客户对账”改名为“入账”，原“供应商对账”改名为“出账”。

## 银行流水

保留现有进账/出账、金额、日期、银行流水号、对方、备注、账户、凭证、编辑、删除和恢复。

增加一个普通文本字段“合同号”，允许留空，只用于列表显示和搜索；不建立关联状态，不做自动匹配，也不阻止保存。

## 入账

系统合同继续自动出现在入账列表。页面顶部增加“添加收款”。

员工只填写客户、合同号、合同金额、已经收到、收款日期和备注。系统自动计算还差多少钱，保存后直接进入入账列表，不走审批。

列表与操作使用“合同金额、已收、还差、添加收款、查看记录、修改、完成”等日常用语。

## 出账

系统采购单继续自动出现在出账列表。页面顶部增加“添加付款”。

员工只填写供应商、合同号或采购单号、总金额、已经支付、付款日期和备注。系统自动计算还差多少钱，保存后直接进入出账列表，不走审批。

列表与操作使用“总金额、已付、还差、添加付款、查看记录、修改、完成”等日常用语。

## 规则

- 输入已有编号时提示重复，避免同一笔钱被录入两次。
- 不新增审批、关联状态或额外工作台。
- 金额修改和冲销继续保留操作人、时间和原因。
- 中文、英文和西班牙文界面同时更新。
